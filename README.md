## 🎨 Design Philosophy

This website features an **Apple-style design** characterized by:

- **Clean & Minimal**: Emphasis on simplicity and elegance
- **Neutral Palette**: White, off-white, soft gray, charcoal, and subtle accent colors
- **Modern Typography**: System fonts (SF Pro Display, Inter) for a premium feel
- **Large Hero Sections**: Prominent introductory sections on each page
- **Elegant Spacing**: Generous whitespace for a premium, uncluttered feel
- **No Flashy Elements**: Subtle, sophisticated design without heavy gradients or bright colors

## 🚀 Getting Started

### Local Development

1. **Open the website**: Simply open `index.html` in a web browser
2. **No build process required**: This is a static website with no dependencies
3. **File structure**: All files are organized in a clean, flat structure

### Customization

#### Colors
Edit CSS variables in `css/style.css`:
```css
:root {
    --color-white: #ffffff;
    --color-off-white: #fafafa;
    --color-charcoal: #1d1d1f;
    --color-accent: #0071e3;
    /* ... more colors */
}
```

#### Typography
Modify font variables:
```css
:root {
    --font-primary: -apple-system, BlinkMacSystemFont, 'SF Pro Display', ...;
    --font-size-base: 1rem;
    /* ... more typography */
}
```

#### Content
- Edit HTML files directly to update content
- All text content is easily accessible in the HTML
- Company information is centralized in the footer
